清仓决定的问题不在于判断准不准，而在于**理由和情绪无法区分**。下跌带来的压力会伪装成逻辑判断，浮亏会伪装成"这个标的变差了"。

解决办法不是提高自控力，而是事先定义什么算理由、什么不算。清单化之后，判断从"我感觉"变成"是否符合条目"。

## 第一张清单：不构成清仓理由的情形

| 情形 | 为什么不算理由 |
| --- | --- |
| 浮盈 / 浮亏 | 持仓成本是你的私人信息，与资产未来现金流无关 |
| 短期波动、跑输指数 | 没有定义观察窗口和基准，任何时点都能得出相反结论 |
| 产品类别本身（如"它是主动基金"） | 类别是买入前就已知的属性，不是新信息 |
| 宏观判断、市场环境 | 不可证伪，且与具体标的的持有逻辑没有映射关系 |
| 存在更好的替代标的 | 相对排序不构成卖出现有标的的理由，只是买入另一个的理由 |
| 持仓重复度过高 | 重复度只独立报告，不写入清仓结论——它是组合层面的问题，不是标的层面的问题 |

这张清单的价值在于它是**否证性**的。它不告诉你什么时候该卖，但能挡掉大部分伪理由。

注意"存在更好替代"和"重复度"两条：它们描述的是组合结构，而不是标的本身。把它们混进清仓结论，会让一个组合优化问题伪装成标的判断问题，之后无法复盘到底是哪一层出了错。

## 第二层检验：赛道逻辑是否还成立

只有当第一层全部不成立时，才进入这一层。

赛道逻辑失效只有三种途径：

1. **买入理由被证伪**。注意是证伪，不是"表现不好"。理由如果是"创新药需求长期存在"，证伪它需要的是需求端出现了结构性逆转的证据，不是药企股价半年没动。
2. **理由已兑现，但缺新理由**。买入时预期的事情发生了，而当初的估值假设已经消化完——这是逻辑上的正常终点，不是失败。
3. **出现买入时未预料、且不可接受的新风险**。两个限定词都不能省。政策变化、技术路线被替代、核心管线失败都属此类；竞争加剧本身通常不属此类，因为它在买入时就应该被预期到。

## 第三层：工具适配性

这一层和赛道逻辑**分开做**，不混在一起判断。深层逻辑没问题，不代表手上这个工具还合适。

- 风格漂移（须注明对应披露期，不能拿短期持仓变动下结论）
- 基金经理变更、规模超出策略容量、费率或合同条款变更
- 指数编制规则变更、跟踪误差持续扩大
- 规模接近清盘线
- C 类份额的销售服务费长期侵蚀收益

这些都是可查证的事实，不涉及对未来的判断，所以处理起来最干净——查到就处理，查不到就不动。

## 执行顺序不能颠倒

必须先做第二层、再做第三层。反过来会产生一个隐蔽的错误：当赛道逻辑已经失效时，因为工具一切正常（经理没换、跟踪误差很小）而选择继续持有。

工具正常只说明**它很好地执行了它该做的事**，不说明这件事还值得做。

反之亦然：赛道逻辑成立而工具出了问题，处理方式是换工具，不是退出这条赛道。这两类结论导向完全不同的操作，所以必须分两次判断，不能压成一个"卖/不卖"。

## 记录要求

每次卖出前写一句话，格式固定：

> 理由层级（赛道逻辑 / 工具适配性）+ 具体条目 + 可查证的证据 + 证据的时间戳

写不出来的，就不要执行。这个约束的作用不是让你决策更慢，而是让三个月后的你能判断这次操作是判断对了，还是运气对了。**没有记录的决策无法积累。**

如果某一层确实查不到证据，结论就是"证据不足"，而不是"倾向卖出"。这两者的差别在下一轮决策里会放大。
