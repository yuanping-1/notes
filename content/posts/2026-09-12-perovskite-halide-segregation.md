混合卤素钙钛矿 $\mathrm{APb(I_{1-x}Br_x)_3}$ 是叠层电池顶电池的主要候选体系：调节 Br 含量可以把带隙从 1.6 eV 连续推到 2.3 eV，正好覆盖与硅底电池匹配的理想区间。问题在于，这个带隙在光照下会自己跑掉。

## 现象：光照诱导的可逆带隙收缩

Hoke 等人在 2015 年报道了一个当时不太被理解的观察：$\mathrm{MAPb(I_{0.6}Br_{0.4})_3}$ 薄膜在连续光照几分钟内，光致发光峰从约 1.85 eV 红移到 1.68 eV 附近，且远低于该组分的平均带隙。关灯后，峰位在数小时到数天内缓慢恢复。

这不是降解。判据很直接——如果是降解，恢复过程不会发生，而且 XRD 会上出现 $\mathrm{PbI_2}$ 的特征峰。相分离是可逆的，$\mathrm{PbI_2}$ 的析出不可逆。

目前的共识是：光照下光生载流子被局域的富碘畴捕获，形成低带隙的 I-rich 相，周围留下列富溴的基体。整个过程由卤素离子的迁移驱动，而不是化学分解。

带隙与卤素比例的关系可以用 bowing 方程描述：

$$
E_g(x) = (1-x)\,E_g(\mathrm{I}) + x\,E_g(\mathrm{Br}) - b\,x(1-x)
$$

其中 bowing 系数 $b$ 在混合卤素体系中约为 0.2–0.3 eV。相分离发生时，薄膜内出现两个局域带隙，而不是一个平均带隙——这是观测到双峰或发生大幅红移的物理来源。

## 机制：离子迁移

钙钛矿的离子迁移激活能远低于共价半导体。软晶格、低形成能的空位、以及 $6s^2$ 孤对电子带来的弱 Pb–I 键合，共同导致了这一点。

| 迁移物种 | 激活能 $E_a$ (eV) | 主要路径 | 文献中的分散度 |
| --- | --- | --- | --- |
| $\mathrm{V_I^+}$（碘空位） | 0.1 – 0.6 | 沿 ⟨110⟩ 通道 | 极大 |
| $\mathrm{MA^+}$ | 0.5 – 0.9 | 晶格间隙 | 中等 |
| $\mathrm{Pb^{2+}}$ | > 1.5 | 基本不动 | 小 |

碘空位的激活能文献值跨度超过 0.4 eV，这个分散度本身就说明问题：不同测量方法测的其实是不同的东西。DFT 算的是理想晶格中的跃迁势垒；阻抗谱测的是多晶薄膜中含晶界、含缺陷的整体电导；而变温 PL 测的是相分离起始温度，更接近热力学边界而不是动力学势垒。**跨方法比较激活能数字是没有意义的**，同一个体系给出 0.1 和 0.6 都可以是对的。

温度依赖用 Arrhenius 关系描述：

$$
k(T) = k_0 \exp\!\left(-\frac{E_a}{k_B T}\right)
$$

由于指数关系，室温下 $E_a$ 差 0.2 eV 对应迁移速率差约三个数量级。这解释了一个现象：相分离在光照下快速发生，但在室温暗态下恢复极慢——同一套机制，两个方向的有效势垒并不对称。

> 光照并不直接"推动"离子，而是通过改变局域载流子浓度和势能面降低了迁移的有效势垒。所以相分离速率对光强的依赖弱于线性，这与实验上看到的现象一致。

## 表征证据：怎么判断是相分离，不是降解

三个手段交叉验证，单看任何一个都容易误判：

- **PL 光谱**：红移说明低带隙畴形成。但要注意红移也可能来自自吸收或散射。判据是看是否出现**双峰**，以及是否伴随积分强度的显著下降。
- **XRD**：相分离会在原主峰旁出现卫星峰或峰形展宽，峰位移动通常小于 0.1°。而降解会出现 $\mathrm{PbI_2}$ 在 12.7° 附近的独立峰——这是两件事的分界线。
- **时间尺度**：相分离在分钟量级发生、小时到天量级恢复；降解通常是单向的、单调的。

处理 XRD 时间序列时，峰位精度比绝对强度重要得多，所以拟合要用整个峰形而不是取极值点：

```python
import numpy as np
from scipy.optimize import curve_fit


def pseudo_voigt(x, amp, center, sigma, eta, baseline):
    """伪 Voigt：Gaussian 与 Lorentzian 按 eta 混合。
    单用 Gaussian 会低估含微应变样品的峰尾，导致峰位系统性偏移。"""
    gauss = np.exp(-((x - center) ** 2) / (2 * sigma ** 2))
    lorentz = 1.0 / (1.0 + ((x - center) / sigma) ** 2)
    return amp * (eta * lorentz + (1 - eta) * gauss) + baseline


def track_peak_shift(two_theta, frames, guess=(1.0, 14.0, 0.1, 0.5, 0.0)):
    """逐帧拟合同一衍射峰，返回峰位随时间的演化。

    边界固定在对齐后的窗口内，否则相邻峰的尾巴会把中心拽走。
    """
    centers = []
    for frame in frames:
        popt, _ = curve_fit(
            pseudo_voigt, two_theta, frame,
            p0=guess,
            bounds=([0, guess[1] - 0.5, 1e-3, 0, -np.inf],
                    [np.inf, guess[1] + 0.5, 1.0, 1, np.inf]),
            maxfev=20000,
        )
        centers.append(popt[1])
        guess = tuple(popt)  # 用上一帧的解做初值，保证帧间连续
    return np.array(centers)
```

用上一帧的解作为下一帧初值是关键。若每帧都从同一个固定初值出发，峰位在 0.01° 量级的帧间抖动会积累成假的"漂移"信号，足以让人误判相分离已经发生。

## 抑制策略及其代价

按有效性排序，同时标注代价——没有免费方案：

1. **减小晶粒尺寸 / 增加晶界钝化**。晶界会钉扎卤素迁移。代价是晶界本身是复合中心，开路电压通常下降。
2. **三阳离子 / 三卤素组分**（Cs/FA/MA + I/Br）。熵稳定的立方相抑制了分离。代价是带隙调节精度下降，Br 的引入效率变低。
3. **添加微量 $\mathrm{KI}$ 或其他碘源**。补充碘空位抑制迁移。代价是过量碱金属离子本身会迁移，长期稳定性存疑。
4. **降低光照强度或工作温度**。这在实验室有效，但对实际工况没有意义。

## 还没解决的问题

- 相分离究竟是**热力学**上光生载流子改变了自由能面的稳定点，还是**动力学**上迁移势垒被降低？两种图景在很多实验上都能拟合，判别性实验还没做干净。
- 文献中报道的"相分离阈值"大多基于 PL 测量。PL 探测的是辐射复合最强的区域，对少数相敏感度极高。**用 PL 判断相分离的起始点，会系统性地早于体相的实际转变点。** 这个偏差有多大，取决于探针深度和载流子扩散长度。
- 逆过程（暗态恢复）的激活能测得更少，而它决定了器件在实际昼夜循环下的寿命。这一块的数据比正过程稀薄得多。

下一步想把这个体系在变温 GIWAXS 下做一套完整时间序列，看相分离的起始是否与晶格热膨胀的拐点重合——如果重合，那更支持热力学解释。
