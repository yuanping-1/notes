时间分辨光致发光（TRPL）测的是载流子复合动力学，但衰减曲线本身不携带物理含义——含义来自你选的模型。这一步选错，后面的解释全是空转。

## 先问一个问题：你要测什么

不同目的对应不同模型，不能通用：

| 目的 | 适用模型 | 关键前提 |
| --- | --- | --- |
| 比较表面钝化效果 | 双指数，取慢分量 | 体寿命已知且样品间一致 |
| 提取体寿命 | 双指数 + 已知表面复合速度 | 需要独立测得 $S$ |
| 判断陷阱密度 | 拉伸指数，看 $\beta$ | 需排除 IRF 影响 |
| 组分变化的相对比较 | 平均寿命 $\langle\tau\rangle$ | 仅同批次同条件可比 |

如果只是想横向比较同一批样品的钝化效果，双指数足够。想报"体寿命"的数字，就必须有独立的 $S$ 或膜厚序列。

## 常见做法为什么错

最普遍的做法是取衰减到 $1/e$ 的时间当作寿命。在钙钛矿里这几乎总是错的：

- 衰减不是单指数，$1/e$ 时间落在两个分量的混合区，不对应任何单一过程；
- 快分量常常被仪器响应函数（IRF）卷积掉，$1/e$ 时间实际由 IRF 宽度决定；
- 有陷阱填充和离子迁移的长尾时，$1/e$ 点会被完全淹没。

另一种错误是把快分量解释成"表面复合"。它也可能是 IRF 的残余、或陷阱态的快速俘获。两者的区别在于**是否随激发强度变化**：真正的复合过程依赖载流子浓度，IRF 残余不依赖。做一次强度依赖测量就能区分，成本很低，但漏掉的人很多。

## 数学形式

双指数、用于平均寿命：

$$
I(t) = A_1 e^{-t/\tau_1} + A_2 e^{-t/\tau_2},
\qquad
\langle\tau\rangle = \frac{\sum_i A_i \tau_i^2}{\sum_i A_i \tau_i}
$$

注意权重是 $A_i \tau_i^2$ 而不是 $A_i$。用简单加权平均会把快分量算得过重，因为它的振幅 $A_1$ 通常远大于 $A_2$，但它贡献的积分面积小。

色散（拉伸）指数，用于存在宽分布陷阱态的情形：

$$
I(t) = I_0 \exp\!\left[-\left(\frac{t}{\tau}\right)^{\beta}\right], \quad 0 < \beta \le 1
$$

$\beta = 1$ 退回单指数。$\beta$ 显著小于 1 说明寿命不是单一值而是有分布，此时报一个"寿命"数字本身就是误导——应当报 $\beta$ 和分布宽度。

## 实现：必须卷积 IRF

当寿命与 IRF 宽度同量级时，不卷积 IRF 会得到系统性偏短的寿命，偏差可达 30% 以上。

```python
import numpy as np
from scipy.optimize import least_squares
from scipy.special import erfc


def irf(t, t0, sigma):
    """高斯 IRF 的累积形式。

    用 erfc 而不是直接对高斯做卷积：解析式更快，且避免数值卷积带来的额外展宽。
    """
    return 0.5 * erfc(-(t - t0) / (np.sqrt(2) * sigma))


def model(t, tau1, tau2, frac, t0, sigma, amp):
    """双指数衰减与 IRF 卷积后的结果（离散化卷积）。"""
    decay = (1 - frac) * np.exp(-t / tau1) + frac * np.exp(-t / tau2)
    decay = np.maximum(decay, 1e-12)  # 防止下溢后 log 出 nan
    pulse = np.exp(-0.5 * ((t - t0) / sigma) ** 2)
    pulse /= pulse.sum()  # 归一化，保证卷积不改变积分面积
    return amp * np.convolve(decay, pulse, mode="full")[: t.size]


def fit_trpl(t, y, p0=(0.5, 5.0, 0.3, 0.5, 0.05, 1.0)):
    """拟合 TRPL 衰减，返回参数与拟合质量。

    注意：这里的平均寿命按 A_i * tau_i^2 加权。
    """
    def residual(p):
        return model(t, *p) - y

    result = least_squares(
        residual, p0,
        bounds=(
            [0.01, 0.01, 0.0, -1.0, 0.01, 0.0],
            [10.0, 200.0, 1.0, 2.0, 0.5, np.inf],
        ),
        method="trf",
        # 参数尺度差异大（ns 与无量纲混在一起），按实际量级缩放
        x_scale="jac",
    )

    tau1, tau2, frac, _, _, _ = result.x
    avg = ((1 - frac) * tau1**2 + frac * tau2**2) / ((1 - frac) * tau1 + frac * tau2)
    return {
        "params": result.x,
        "avg_lifetime": avg,
        "cost": 2 * result.cost / (t.size - len(result.x)),  # 约化卡方，比残差平方和可比
    }
```

`x_scale="jac"` 这一行不是可选项。参数里混着 ns 量级的寿命和无量纲的比例，默认缩放会让优化器在寿命方向上走得过慢、在比例方向上走过头，结果是收敛到边界而不是极小值。

## 判断拟合是否可信

看三个量，不看 $R^2$：

1. **约化卡方**是否接近噪声水平（约 1.0）。远大于 1 说明模型欠拟合。
2. **残差是否有结构**。画出残差图，如果呈单调趋势或系统性的 S 形，说明少了一个分量。随机散布才是好的。
3. **参数是否落在边界上**。如果 $\tau_1$ 顶到上界，说明数据和模型不匹配，此时任何报出的数字都没有意义。

最后一条最容易被忽略。优化器不会告诉你它撞墙了，但边界上的参数意味着拟合结果由你设的边界决定，不由数据决定。

## 一个仍未解决的争议

双指数的两个分量究竟对应什么物理过程，在钙钛矿领域没有共识。常见的三种解释——体复合/表面复合、自由载流子/束缚激子、辐射/非辐射通道——都能拟合同一组数据。

判别方法是做**强度依赖**：如果慢分量随激发强度出现双分子复合特征（$\tau \propto I^{-1/2}$），那它更可能是自由载流子；如果不随强度变化，更可能是陷阱俘获。只做单强度测量就下结论，是在给一个不可判定的问题假装答案。
