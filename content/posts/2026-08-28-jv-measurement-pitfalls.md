钙钛矿太阳能电池的 J-V 测量没有看起来那么直接。同一片器件，换一个实验室、换一次扫描设置，效率数字可以差 20% 以上。问题出在一批被广泛沿用但缺乏物理依据的默认习惯。

## 陷阱一：不做预处理直接扫

钙钛矿器件有显著的"历史依赖"：测量结果取决于器件在测量前的状态——是否经历过光照、上一次偏压是多少、静置了多久。

未经光照的器件在第一次扫描时效率通常偏低，光照浸泡后效率上升。上升的幅度和速度取决于离子分布，而离子分布在暗态下会缓慢弛豫回初始状态。

**推荐做法**：先做至少 60 秒的开路光照浸泡（light soaking），再开始测量；并在文中明确写出这个预处理条件。不写预处理条件的效率数字，别人无法复现。

## 陷阱二：只做一个扫描方向

迟滞（hysteresis）在钙钛矿里是常态。正扫（短路→开路）和反扫（开路→短路）给出不同结果，差异可达相对 10–20%。

只报效率更高的那个方向，是最常见的报告偏差。**最低要求是两个方向都报**，并说明稳定化效率。

迟滞的成因仍有争议——离子迁移、界面电荷积累、铁电效应都有人支持。但作为测量问题，处理方式与成因无关：两个方向都测，报出差异。

## 陷阱三：扫描速率定得随意

扫描速率对迟滞的幅度影响很大。慢扫（接近准稳态）得到的结果通常更接近真实工作状态；快扫会放大瞬态效应。

常见做法是沿用一个固定值（比如 100 mV/s），理由是"和文献一致"。但文献之间并不一致，而且**扫描速率的影响依赖于器件的离子迁移特征时间**，不同器件的最佳值本来就不同。

**推荐做法**：做一组扫描速率依赖（例如 10 / 50 / 100 / 500 mV/s），看效率是否收敛。能收敛的速率区间才是可信的测量条件。

## 陷阱四：有效面积没有独立核定

$J_{sc}$ 除以的是你**声称**的面积，不是实际的受光面积。金属掩膜的开孔面积、边缘的散射光、以及封装带来的额外受光，都会带来偏差。

效率越高，这个偏差越致命：绝对效率达到 25% 以上时，5% 的面积误差会带来超过 1 个百分点的效率误报。

做法：用独立的面积测量（成像法或显微测量）核定掩膜开孔，而不是用设计值；同时说明是否扣除了金属栅线的遮光面积。

## 陷阱五：温度没有控制

$V_{oc}$ 有约 $-2\ \mathrm{mV/K}$ 的温度系数。器件在 1 sun 光照下自身升温 5–10 K 是常见的，未经温控的夹具会让 $V_{oc}$ 系统性偏低 10–20 mV。

**推荐做法**：用带温控的样品台，稳定在 $25 \pm 1\ ^\circ\mathrm{C}$。

## 陷阱六：把扫描效率当成器件效率

J-V 扫描是一个快速过程，而实际工作是在最大功率点（MPP）持续输出。两者可以差很多，尤其在迟滞明显的器件上。

**推荐做法**：报告稳态 MPP 跟踪结果（至少 60 秒），并注明跟踪期间效率的衰减。这是目前公认更接近真实性能的数字。

## 陷阱七：参数提取不交代算法

从 J-V 曲线提取 $V_{oc}$、$J_{sc}$、$FF$ 时的插值方式不同，会得到不同的数字：

$$
FF = \frac{P_{max}}{J_{sc}\, V_{oc}},
\qquad
\mathrm{PCE} = \frac{J_{sc}\, V_{oc}\, FF}{P_{in}}
$$

其中 $P_{in} = 100\ \mathrm{mW/cm^2}$（AM1.5G，1 sun）。$V_{oc}$ 是 $J = 0$ 处的外推值，$J_{sc}$ 是 $V = 0$ 处的插值——两者都应该用**线性插值确定跨零点**，而不是取数据点中绝对值最小的那个点。

采样率不高时，直接用最近点会让 $J_{sc}$ 系统性地偏小。这是一个纯粹的实现问题，但报告里经常不写清楚。

```python
import numpy as np


def extract_parameters(voltage, current_density, power_in=100.0):
    """从 J-V 曲线提取光伏参数。

    Voc 与 Jsc 通过线性插值定位跨零点：
    数据点稀疏时直接取最近点会引入系统性偏差，且偏差方向固定（Jsc 偏小）。
    """
    v = np.asarray(voltage, dtype=float)
    j = np.asarray(current_density, dtype=float)

    # 扫描方向不一致时先按电压升序排列，否则插值区间会取反
    order = np.argsort(v)
    v, j = v[order], j[order]

    # 短路电流密度：J = 0 处的电压对应电流
    jsc = float(np.interp(0.0, v, j))

    # 开路电压：先找到电流变号的两个相邻点，再在该区间内线性插值求根
    sign_change = np.where(np.diff(np.sign(j)) != 0)[0]
    if sign_change.size == 0:
        raise ValueError("曲线上找不到电流过零点，检查数据是否包含开路电压附近")
    k = sign_change[-1]  # 取最后一个过零点，避开低电压区的异常抖动
    v1, v2, j1, j2 = v[k], v[k + 1], j[k], j[k + 1]
    voc = float(v1 - j1 * (v2 - v1) / (j2 - j1))

    # 最大功率点
    power = v * j
    idx = int(np.argmax(power))
    pmax = float(power[idx])

    ff = pmax / (jsc * voc) if jsc * voc else 0.0
    return {
        "voc_mV": voc * 1000,
        "jsc_mA_cm2": jsc,
        "ff": ff,
        "pce": pmax / power_in,
        "v_mpp": float(v[idx]),
        "j_mpp": float(j[idx]),
    }
```

`sign_change[-1]` 取最后一个过零点是刻意的：低电压区常有测量噪声导致的伪过零，取第一个会得到明显偏低的 $V_{oc}$。

## 一条通用原则

上面七个陷阱有一个共同点：**它们都不是操作错误，而是默认习惯的问题。** 每个习惯单独看都有理由（省时间、和文献一致、设备默认设置），但累积起来足以让效率数字失去跨实验室的可比性。

因此报告时必须交代的是**条件**，不只是结果：预处理方式、扫描方向与速率、面积核定方法、温度、以及是扫描效率还是稳态效率。缺少这些条件的效率数字，无论高低，都不构成证据。

钙钛矿领域的效率认证流程（如独立第三方认证）之所以要求固定协议，正是因为这些问题在早期文献里造成了大量不可复现的数字。
